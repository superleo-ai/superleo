SuperLeo

让你手上的几个 Agent 一起干活，用你自己的订阅。 Your agents, working together, on your own subscriptions.

我手上有好几个 Agent：Mac 上的 Claude Code，服务器上的 Codex，家里跑着的 OpenClaw。每个都好用，但它们互相不认识，我只能在几个窗口之间来回传话。所以写了 SuperLeo。它装在你自己的电脑上，把各台机器上的 Agent 连起来：你说一件事，它交给最合适的那个去做，需要的话分给几个一起做，最后把结果合成一个回答给你。它们用的都是你已经付过钱的订阅，不用另买一份 API。代码是开源的。 I have a few agents: Claude Code on my Mac, Codex on a server, OpenClaw running at home. Each one is good, but they don't know about each other, and I ended up passing messages between windows. So I wrote SuperLeo. It runs on your own computer and links the agents on all your machines. You ask for something once; it goes to whichever agent suits it, or to several at once, and you get one answer back. They run on the subscriptions you already pay for, so there's no second API bill. The code is open.

几个 Agent，一起干活Several agents, one job

  • 你已经有的The ones you have Claude Code、Codex、opencode、OpenClaw 等，装在哪台机器上都行。它在每台机器上找到它们，不用重新配置。Claude Code, Codex, opencode, OpenClaw and others, on any of your machines. It finds them where they are; nothing to set up again.
  • 你自己的订阅Your own subscriptions 每个 Agent 照常用你的 Claude、ChatGPT 订阅登录。SuperLeo 不卖额度，也不经手你的账号。Each agent signs in with your Claude or ChatGPT plan as it always has. SuperLeo sells no credits and never touches your accounts.
  • 多台机器Many machines Mac、Windows、Linux 服务器都能加进来。要在那台机器上做的事，就在那台机器上做。Add Macs, Windows PCs and Linux servers. A job that belongs on one machine runs there.
  • 共享记忆Shared memory 一个 Agent 查到的、你交代过的，别的 Agent 也知道，不用每次从头讲。What one agent found out, or what you told it, the others know too. No starting over each time.

平时怎么用How I use it

早上它把今天的日程和待办整理好推到手机上。临时想起一件事，对着手表说一句，它会记下来，到时间提醒我。 In the morning it sends today's schedule and to-dos to my phone. When something comes to mind, I say it to my watch, and it reminds me at the right time.

改代码交给 Claude Code，查资料交给另一台机器上的 Codex，几件事同时跑，做完了告诉我结果。在 3D 视图里能看到每个 Agent 正在做什么。需要我确认的事，手机上会先问我。 Code changes go to Claude Code, research to Codex on another machine, several things at once, and I hear back when they're done. The 3D view shows what each agent is doing. Anything that needs my OK, my phone asks first.

SuperLeo 自己的模型也由你决定：可以直接用 Claude Code 当大脑，也可以接任何兼容 OpenAI 接口的服务，或你自己跑的模型。 You also choose what SuperLeo itself thinks with: Claude Code on your plan, any OpenAI-compatible service, or a model you run yourself.
